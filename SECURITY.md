# Security / Безопасность

[English](SECURITY_EN.md) | Русский

## Что остаётся только у клиента

- приватный ключ кошелька;
- seed-фраза;
- Polymarket API key, secret и passphrase;
- токен Telegram-бота;
- пароль и SSH-ключ VPS.

Ни один из этих секретов не нужен для покупки или выпуска лицензии.

## Что может хранить магазин

- Telegram ID покупателя;
- номер заказа;
- безопасный код привязки VPS;
- тип и срок лицензии;
- версию выданного продукта;
- идентификатор и статус платежа;
- выбранный язык и источник перехода.

## Проверка клиентской сборки

Перед выпуском архив проверяется на известные форматы Telegram-токенов, приватных ключей, заполненных API secrets и локальных путей разработчика. Публичная контрольная сумма позволяет проверить, что скачанный архив совпадает с опубликованной версией.

Не публикуйте приватные ключи, токены, пароли или полные файлы настроек в GitHub Issues. Для приватного обращения используйте [@algoproof_support](https://t.me/algoproof_support).
