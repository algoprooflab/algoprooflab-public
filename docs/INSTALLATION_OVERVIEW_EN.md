# Installation overview

[Русская версия](INSTALLATION_OVERVIEW_RU.md)

The client archive contains the full step-by-step guide. The general process is:

1. Rent a clean Ubuntu VPS.
2. Upload the client archive.
3. Run the installation script.
4. Create a personal Telegram bot through BotFather.
5. Enter credentials directly on the VPS.
6. Generate the VPS code used for license binding.
7. Enter the trial or permanent license key.
8. Start in demo mode.
9. Verify data access, control and notifications.
10. Enable the smallest live stake only after the checks pass.

Only the VPS code is sent to the shop. The wallet private key, Telegram token, Polymarket API secret and VPS password stay with the buyer.

The first supported setup is a clean Ubuntu VPS. Home Windows and macOS installations are not the primary supported configuration for version 1.0.
