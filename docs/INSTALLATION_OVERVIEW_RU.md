# Как выглядит установка

Полная пошаговая инструкция входит в клиентский архив. Общая последовательность:

1. Покупатель арендует чистый Ubuntu VPS.
2. Загружает архив на свой сервер.
3. Запускает установочный сценарий.
4. Создаёт собственного Telegram-бота через BotFather.
5. Вводит свои данные непосредственно на VPS.
6. Получает код VPS для лицензии.
7. Вводит пробный или постоянный лицензионный ключ.
8. Сначала включает деморежим.
9. Проверяет подключение и уведомления.
10. Только после этого по своему решению включает минимальную реальную ставку.

Продавцу передаётся только код VPS. Приватный ключ, Telegram-токен, Polymarket API secret и пароль VPS остаются у покупателя.

Поддерживаемая первая конфигурация: чистый Ubuntu VPS. Установка на домашний Windows или macOS не является основной поддерживаемой схемой первой версии.
