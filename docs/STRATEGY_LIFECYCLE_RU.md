# Жизненный цикл стратегии

| Статус | Значение |
|---|---|
| `RESEARCH` | Идея исследуется и не предлагается клиентам |
| `VERIFICATION` | Стратегия набирает двухмесячную историю |
| `ACTIVE` | Прошла критерии и доступна для использования |
| `WATCH` | Показатели ухудшились, новые продажи приостановлены |
| `RETIRED` | Стратегия снята с использования |
| `FAILED` | Не прошла проверку и не продавалась |

Новая стратегия не считается обновлением только потому, что её код написан. Она должна пройти установленный период проверки, сравнение двух частей и стресс-тест расходов.

Технические исправления движка и новые торговые стратегии — разные виды обновлений. Исправления безопасности и совместимости выпускаются отдельно от коммерческих пакетов стратегий.
