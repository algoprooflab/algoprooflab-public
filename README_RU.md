# AlgoProof Lab

**Проверяемые торговые боты, стратегии и исследования рынков прогнозов.**

[English](README.md) | [Русский](README_RU.md)

![AlgoProof Lab](assets/algoprooflab-avatar-v1.png)

AlgoProof Lab занимается исследованием автоматической торговли с 2022 года. Репозиторий содержит проверяемые отчёты, примеры сделок, документацию и историю версий первого продукта для рынков Bitcoin Up/Down 5m на Polymarket.

Исходный код коммерческой стратегии и клиентская сборка здесь не публикуются. Клиент запускает программу на собственном VPS и самостоятельно контролирует ключи, средства и ограничения риска.

## Реальная торговля лаборатории

Текущий непрерывный LIVE-журнал: **15 сентября — 7 октября 2026 года**.

| Показатель | Значение |
|---|---:|
| Завершённых реальных сделок | 469 |
| Сделок в плюс / минус | 271 / 198 |
| Доля прибыльных сделок | 57,78% |
| Итог после комиссий | **+485,82 USDC** |

За этот период лаборатория проверяла несколько стратегий. Это результат лабораторного счёта в целом, а не заявленный результат одного продаваемого пакета. [Подробное объяснение](docs/LIVE_TRADING_RU.md).
